# Contributing



Bug reports, typography fixes, and OpenType improvements are welcome.



When reporting an issue, please include:



* affected glyph(s) or feature;
* application and operating system used for testing;
* expected result;
* actual result;
* a minimal reproduction string when possible.



For font changes, please provide the modified FontForge source when possible and explain the intended change.



Contributions intended for inclusion in the project must be compatible with the license terms applicable to the contributed material.
