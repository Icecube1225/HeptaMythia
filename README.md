# HeptaMythia



A custom typeface with OpenType ligatures and mark positioning for specialized phonetic typography.



## Overview



HeptaMythia is an original typeface designed from scratch by Icecube1225.

The project includes custom glyph outlines and OpenType features for ligatures, mark positioning, and specialized phonetic typography.

The current release is **v1.0.2**.

## Installation



### Windows



1. Download the `.otf` file from the desired release.

2. Open the file and choose **Install** in Windows Font Viewer, or right-click it and choose **Install**.

3. Restart an application if the font does not appear immediately.



### Other systems



Use the normal font installation procedure of the operating system.



## OpenType features



HeptaMythia uses OpenType features including:



- `liga` for ligature substitution.

- `mark` for mark positioning.

- Mark-to-ligature positioning for marks attached to particular ligature components.



Exact feature behavior depends on the text-shaping engine used by the application.



## Source files



The FontForge source is provided in `source/`.

The source contains the glyph outlines, anchors, GSUB/GPOS lookup definitions, and other font-development data needed to study or modify the typeface.

## Trivia

HeptaMythia was designed exclusively for the PHX Puzzle Hunt Society of Nanjing Foreign Language School as the foundation for a puzzle featuring English phoneme substitution. It was first released in their club publication, *NFLS Weekly Puzzles Vol. 016* (*南外周周谜 Vol. 016*).
